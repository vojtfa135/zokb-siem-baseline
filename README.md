# zokb-siem-baseline

**Compliance as Code for ZoKB** — a vendor-neutral baseline that formalizes the
event-logging and cyber-event detection/evaluation requirements of the Czech
NIS2 implementing decrees into machine-readable artifacts (OSCAL catalogs,
logging baselines mapped to ECS/OCSF, and Sigma detection rules).

> 🚧 This repository is being scaffolded. The full structure — OSCAL catalogs for
> **vyhláška č. 409/2025 Sb.** (higher-obligations regime) and
> **vyhláška č. 410/2025 Sb.** (lower-obligations regime), regime profiles,
> logging baseline, seed Sigma rules, coverage mapping, JSON Schemas, and CI —
> is being added via the initial scaffolding pull request.

## Legal sources

- **zákon č. 264/2025 Sb.** — Czech Cybersecurity Act (NIS2 transposition)
- **vyhláška č. 409/2025 Sb.** — security measures, *higher-obligations regime* (§§ 21–23)
- **vyhláška č. 410/2025 Sb.** — security measures, *lower-obligations regime* (§ 9)

## Disclaimer

The verbatim decree text is the authoritative law. The mappings in this
repository are an engineering interpretation to support implementation and are
**not legal advice**.
